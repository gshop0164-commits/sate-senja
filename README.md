Sate Senja (Dusk Satay) — an original Indonesian night-market satay grill game built for the make.fun best cooking game bounty. One cook, one 150-second evening shift at a street stall: skewer chicken, beef, tofu and tempeh, grill them over glowing charcoal, flip each skewer at the right moment before it burns, dip the cooked satay in glossy peanut sauce, plate it with lontong, cucumber and shallots, and serve it at the window before the customer walks away. 5 recipes, a growing night rush, combo bonuses and smoke, embers and string lights.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD / arrow keys or click, use a station with E, Space to start, P to pause.
